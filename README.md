# ImpactLab

Projet 1 - Site vitrine associatif / ONG

Thème

- Humanitaire

Présentation

ImpactLab est une association humanitaire fictive dont l'objectif est de venir en aide aux personnes en situation de vulnérabilité. Le site présente la mission de l'association, ses actions, les événements à venir ainsi qu'un formulaire de contact et de don.

Conflit de merge

Au cours du projet, un conflit de fusion a été rencontré lors de l'intégration de plusieurs modifications sur la branche principale. Le conflit a été résolu en comparant les changements réalisés sur les différentes branches, puis en conservant la version correcte avant de finaliser la fusion.
